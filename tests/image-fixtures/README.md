# Synthetic codec fixtures

Every image in this folder is an artificial 47 × 37 pixel pattern generated by `generateFixtures.m`. None is a camera capture or an experimental measurement. The images contain only a deterministic integer ramp; their TIFF metadata contains dimensions, compression and basic grayscale tags.

For zero-based `x = 0..46` and `y = 0..36`:

```text
16-bit samples = (131*x + 1009*y) mod 65536
8-bit samples  = (131*x + 1009*y) mod 256
32-bit samples = 4100000000 + 131*x + 1009*y
```

The first two 32-bit samples are replaced with 0 and 4294967295 to test the endpoints. Indexed images use an identity grayscale palette. The optional JPEG can be generated locally from the same 8-bit pattern at quality 98; it is excluded from this public repository and is not required by the automated tests.

The variants exercise uncompressed, PackBits, LZW and Deflate TIFF decoders, PNG bit depths and indexed BMP/PNG/TIFF palettes. `manifest.json` records the expected uncompressed integer samples. Run `generateFixtures` in MATLAB to regenerate the files and manifest. The JavaScript tests compare each decoded lossless sample to that manifest.
