# Sensor DN Power Studio 1.2 verification

The implementation follows the confirmed batch, including the last correction that retains native solid gray triangle arrows. No new chevron design is used in the application.

- Five sidebar sections: Import, Parameters, Image, Results, Save. Image groups preprocessing, ROI, guides and view controls; its settings use the preview's 300 px default width and 22 px group spacing. Existing saved panel dimensions remain respected.
- Import, Calculate and Export share the same primary-button styling. Save has three rows, with a fixed Name label and a full-width Export button.
- Bounded arithmetic parsing supports numbers, decimals, scientific notation, four operators and parentheses, without evaluating JavaScript. Invalid inputs and division by zero block measurement/export. Field limits and whole-pixel ROI dimensions remain enforced. Style fields use the same numeric component.
- Bright green ROI outlines, larger labels, and eight direction-specific resize cursors. Existing handle-first hit testing is retained.
- Histogram controls moved beside its title. The native DN label includes bit depth. Closed four-sided borders, darker bars, a blue mean line and label backgrounds improve visibility.

Applied settings are remembered locally, carried into expanded windows, broadcast to already-open windows, and used by the 4K PNG renderer.
