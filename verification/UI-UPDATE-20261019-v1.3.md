# Version 1.3 verification

## Changes

- Calculate uses the selected Lucide square-function icon.
- Both Import buttons share the same text and arrow-up-from-line icon.
- Results explicitly labels Peak Power Density and Mean Power Density.
- ROI dimension text has no background fill; its green outline, handles and label remain.
- Chart defaults match the requested screenshots: green #367d5e bars at 0.7 opacity;
  blue dashed mean and red solid peak lines of width 2.5; size 16 markers, ticks and
  axis titles; black borders of width 1.5; black ticks and titles; solid light gray
  grid of width 1; white backgrounds; marker label backgrounds off.
- Marker font colors are independent of line colors. Bold and Italic are available
  for markers, ticks, axis titles, filename and results summary. Summary has its
  own font color. Segoe UI remains the chart font with Arial/sans-serif fallbacks.
- A shared independent drawing module renders canvas text for main, preview,
  expanded charts and 4K export. Selectable HTML summary uses matching font styles.
- Existing browser preferences are retained. Older marker and summary colors are
  migrated from their previously shared line and tick colors when needed.

## Validation

- 22 tests pass, including numerical MATLAB fixtures and original export tests.
- New tests cover older saved styles, storage round trips, font/color rendering,
  unchanged numerical labels and line colors independent of marker font colors.
- TypeScript and Vite production build pass.
- Browser checks on the public synthetic sample confirm identical Import icons,
  the selected Calculate icon, no ROI label fill and no Results-label overflow at
  the default 300 px sidebar width.
- Custom marker/tick/title/summary typography applies in preview and main chart;
  summary styles propagate to an already-open expanded window.
- Cancel discards unapplied font edits. Reload retains applied colors and font
  styles. Reset then Apply restores the new defaults.
- An actual browser Export produces five files. Histogram PNG is 3840 x 2160;
  independently chosen mean, peak and summary font colors appear in its pixels.
- Both exported sample images are 800 x 520; the unmarked image exactly equals
  the source sample. TXT is 250 x 130 and XLSX has 32500 numeric cells. Maximum DN
  remains 209 and mean DN remains 113.30815384615384.

Only the public arithmetic-generated synthetic sample was used for verification.
No experimental images or user uploads are included in this update.
